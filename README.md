# Menu Price Editor

Build a simple printable food menu with sections, items and prices, with a live preview.

Single-file app in plain HTML, CSS and JavaScript. No build step, backend or API keys. Data is saved in the browser's localStorage only.

## Run locally

Open `index.html` in a browser.

## Deploy

1. Create a new GitHub repository and upload `index.html` and `README.md` (or run `git init`, `git add .`, `git commit`, then push).
2. Netlify: Add new site, Import an existing project, pick the repository, leave the build command empty and deploy. Or use GitHub Pages: Settings, Pages, deploy from the `main` branch root.
